# TaskFlow 项目开发计划与知识学习计划

## 一、项目基本说明

### 1.1 项目名称

TaskFlow——企业工单与任务协作管理系统。

### 1.2 项目目标

TaskFlow 是一个基于前后端分离架构开发的企业内部管理系统，主要用于解决企业日常工作中的工单处理、任务分配、部门管理和人员协作问题。

通过该项目，掌握 Python 后端开发的核心技术，积累完整项目开发经验，为 Python 后端开发工程师求职和面试做准备。

### 1.3 项目技术栈

| 技术方向     | 使用技术              |
| ------------ | --------------------- |
| 后端语言     | Python 3.11           |
| 后端框架     | Django 5.2            |
| API 框架     | Django REST Framework |
| 身份认证     | SimpleJWT             |
| 前端框架     | Vue 3                 |
| 前端构建工具 | Vite                  |
| UI 组件库    | Element Plus          |
| 前端状态管理 | Pinia                 |
| 数据库       | MySQL 8.0             |
| 后续缓存     | Redis                 |
| 后续容器化   | Docker                |

# 六、知识学习方式与要求

为了确保真正掌握项目技术，后续学习继续采用以下方式：

1. **一次学习一个小节：** 不一次性讲完一整课，避免知识堆积。
2. **结合 TaskFlow 实际业务：** 优先使用项目中的用户、部门、工单和任务场景解释知识。
3. **解释代码执行过程：** 不只说明代码是什么，还要解释为什么这样写。
4. **解释关键参数和方法：** 对重要 ORM 方法、DRF 参数和数据库操作逐一说明。
5. **每节课安排练习：** 通过实际问题检查理解程度。
6. **逐题批改：** 指出回答正确的地方和需要纠正的概念。
7. **掌握后再进入下一节：** 没有理解的知识点先巩固，不盲目推进。
8. **结合面试要求：** 每个重要知识点都要能够用自己的话解释，并能回答常见追问。
9. **开发与学习同步：** 项目开发过程中遇到的新技术，及时补充对应知识。
